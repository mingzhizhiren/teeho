# 卸载

用户要求卸载即授权移除当前系统用户环境中已发现的题火安装，尊重指定 Agent 或项目范围；范围不明最多确认一次。默认保留凭据、历史和任务，无需登录或连接服务。另有清除数据要求时，合并说明范围与影响，沿用已有授权，在删除技能前执行[清理命令](../SKILL.md#账号与清理)。

1. 从安装器记录、当前项目、已发现客户端的技能目录及用户指定位置盘点安装；记录绝对路径、独立副本、符号链接／目录联接（含失效链接）及共享目标。不递归扫描整盘或整个用户目录。
2. 删除前保留操作清单和复查步骤。优先使用安装器已核实的范围参数，否则用系统文件工具处理；只操作经路径、类型和内容确认的题火安装，保护源码、其他技能、客户端配置、用户数据和 Python。
3. Windows 检查 ReparsePoint/Target；链接只删入口，不沿链接递归。共享目录仅在没有保留客户端依赖时删除，依赖未知则保留并说明。安装记录由安装器更新，避免覆盖整个注册记录。
4. 复查全部已发现范围内的路径与安装记录；失效链接不能仅凭 `Test-Path=False` 判定已删除。权限不足、记录未清理或共享依赖未查明均属于未完成。

盘点、删除和复查在内部完成；遵守宿主权限要求，必要请求合并处理。核实成功后仅回复“已删除题火”（按用户语言翻译）；部分失败简述原因，详细证据在用户追问时提供。
